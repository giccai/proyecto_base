# Manuscrito

- `main.tex` — documento principal, en la plantilla del journal objetivo.
- `sections/` — una sección por fichero.
- `refs.bib` — bibliografía; **cada entrada con su DOI verificado**.
- `tables/`, `figures/` — **generadas por script** desde `results/`; nunca se editan a mano.
- `cover_letter.md` — carta de presentación (Sprint 6).

Compilar: `make paper`.
